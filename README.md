# The Second Machine Age — галактика слайдов

Интерактивная презентация: 8 сфер в галактике, каждая сфера — один слайд.
Наведи на сферу — появится окно со слайдом, нажми — оно откроется с анимацией.

## Как опубликовать на GitHub Pages
1. Создай репозиторий на GitHub и загрузи в него `index.html` (Add file → Upload files).
2. Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save.
3. Через минуту сайт откроется по адресу `https://<твой-ник>.github.io/<название-репозитория>/`.

Нужен интернет: three.js и шрифты подгружаются с CDN.
